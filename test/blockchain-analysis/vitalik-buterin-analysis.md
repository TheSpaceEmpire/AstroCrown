## 3. Comparative Matrix

| Criterion        | Ethereum L2*                      | Avalanche Subnets           |
|------------------|-----------------------------------|-----------------------------|
| Throughput       | ~2,000–4,000 TPS†                 | >4,500 TPS‡                 |
| Finality         | ~1 min (via L2→L1 challenge)      | <1 sec                      |
| Security Model   | L1‑backed, multi‑party fraud proofs | Probabilistic BFT sampling  |
| Fees             | $1–$5 per tx                      | <$0.01 per tx               |
| Dev Ecosystem    | Mature (Truffle, Hardhat, etc.)   | Growing (AvalancheJS, Subnet SDK) |

\* Aggregated across Arbitrum, Optimism, zkSync.  
† L2 TPS varies by rollup.  
‡ Measured on P-Chain alone.

## 4. Conclusion
Avalanche Subnets offer sub‑second finality and ultra‑low fees, but Ethereum’s L2 ecosystem remains unparalleled in diversity and tool support.
